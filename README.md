# 🤖 AI Customer Support Assistant - Frontend

A modern AI-powered Customer Support Assistant frontend built with React. This application provides an intuitive interface for customers and support agents to manage tickets, communicate with AI, and track support requests efficiently.

---

## 📌 Project Overview

The AI Customer Support Assistant is designed to simplify customer support operations by combining Artificial Intelligence with an easy-to-use web interface.

The frontend communicates with the backend APIs to provide features such as authentication, ticket management, AI-assisted responses, and dashboard analytics.

---

## ✨ Features

- 🔐 User Authentication (Login & Registration)
- 👤 User Profile Management
- 🎫 Ticket Creation & Management
- 📝 Ticket Status Updates
- 🤖 AI Support Chat Interface
- 📊 Dashboard with Ticket Statistics
- 🔍 Search & Filter Tickets
- 💬 Comments & Conversation History
- 📱 Responsive User Interface
- ⚡ Fast and Modern React Application

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/koppakarasagna41-tech/AI-CUSTOMER-ASSISTANT-FRONTEND-1.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```
